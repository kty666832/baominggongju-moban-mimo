# 📋 通用报名工具模板

> 改 config.yaml 就能适配任何报名场景，零代码！

## 快速开始
1. npm install
2. 修改 config.yaml
3. node server.js
4. 打开 http://localhost:3000

## 文件说明
| 文件 | 说明 |
|------|------|
| config.yaml | ⭐ 核心配置文件 |
| server.js | Express 后端服务 |
| database.js | SQLite 数据库操作 |
| public/* | 前端页面文件 |

## 导出数据
打开管理后台 → 输入密码 → 点击「导出CSV」
